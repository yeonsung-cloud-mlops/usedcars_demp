# 중고차 가격 예측 모델

**최신 기본 모델은 트림까지 추가한 5개 Feature 버전이다. [README_trim.md](README_trim.md)에서 최신 사용법과 동일 표본 검증 결과를 확인할 수 있다. 아래 내용은 이전 버전 기록이다.**

이 문서는 초기 3개 Feature 모델의 기록입니다. 현재 모델과 실행 방법은 [루트 README](../README.md), 사고 이력 추가 실험은 [비교 기록](../README_accidents.md)을 참조하세요. 아래 경로와 실행 예시는 당시 기준입니다.

입력은 **제조사+모델, vehicle_age, mileage** 세 가지다. 제조사와 모델명은 사용 편의를 위해 따로 입력받아 내부에서 하나의 범주로 합친다. 목표값은 원본 CSV의 `price`이며, 매물 가격을 예측한다. 실거래 가격이나 2026년 현재 시세를 예측하는 모델은 아니다.

## 사용 방법

Python 3.11에서 실행했다. 필요한 패키지는 `requirements.txt`에 고정했다.

```bash
python3 -m pip install -r requirements.txt
python3 predict.py --make Toyota --model Camry --vehicle-age 5 --mileage 60000
```

`--milage`도 `--mileage`의 별칭으로 지원한다. 가격과 주행거리는 CSV에 저장된 단위 그대로다. CSV에 단위 정의가 없어 통화나 km/mile 변환은 적용하지 않았다. 외부 입력을 연결할 때 원본 데이터의 단위를 확인하고 통일해야 한다.

Python에서 사용할 때:

```python
from price_model import PricePredictor

predictor = PricePredictor()
result = predictor.predict(
    make_name="Toyota",
    model_name="Camry",
    vehicle_age=5,
    mileage=60000,
)
print(result["predicted_price"])
```

차령은 정수이며 `매물 등록 연도 - 차량 연식`으로 정의한다. 2020년에 등록된 2015년식 차량은 5다. 만 나이나 월 단위 경과기간은 아니다. 현재 연도를 과거 행에 일괄 적용하지 않았다.

학습에 없던 제조사·모델 조합, 음수·NaN·무한대, 소수 차령, 전체 학습 범위를 벗어난 입력은 오류로 반환한다. 전체 범위는 차령 0~30, 주행거리 0~300,000이다. 해당 차종의 학습 표본이 100건 미만이거나 해당 차종에서 관측한 차령·주행거리 범위를 벗어나면 결과에 설명을 포함한다. 대소문자와 앞뒤 공백은 정규화한다.

## 데이터 구성

사용자가 지정한 `used_cars_price_prediction.csv`의 2,547,053행을 출발점으로 삼았다. `used_cars_data.csv`에서 21개 컬럼이 모두 일치하는 행을 찾아 `is_new`, `listed_date`, `vin`을 복구했다. 해시로 후보를 찾은 후 실제 모든 컬럼 값의 일치까지 검증했다. 원본 CSV와 기존 `feature_pop.py`는 수정하지 않았다.

| 처리 단계 | 행 수 |
|---|---:|
| 요청한 CSV | 2,547,053 |
| 원본에서 일치한 행 | 2,547,053 |
| VIN·등록일·신차 여부 조합이 여러 개여서 제외 | 83,361 |
| 원본 메타데이터를 하나로 확정 | 2,463,692 |
| 그중 `is_new=False` | 1,505,447 |
| 날짜·차령·VIN 등 유효성 검사에서 제외 | 3,330 |
| 최종 학습·평가 대상 | 1,502,117 |

사고 여부, 트림, 마력, 지역 등은 예측 입력에 사용하지 않는다. `vin`과 `listed_date`는 검증 분리 및 차령 계산에만 사용한다. 원본의 가격 1,000~200,000, 연식 1990~2020, 주행거리 0~300,000 필터는 유지된다.

## 모델 구성

1. 제조사와 모델명을 정규화해 충돌 없는 하나의 문자열 범주로 만든다.
2. `TargetEncoder`로 제조사·모델 범주를 숫자 1개로 변환한다. 이 숫자는 해당 차종의 학습 데이터 로그 가격 수준을 나타내며, 표본 수에 따라 전체 평균 쪽으로 평활화한다. 학습 행에는 5분할 교차 인코딩을 적용해 해당 행의 정답이 그 행의 인코딩에 직접 들어가는 것을 방지한다. 평가 데이터의 정답은 인코딩에 사용하지 않는다.
3. 인코딩 값, 차령, 주행거리의 **숫자 3개**를 `HistGradientBoostingRegressor`에 전달한다. 여러 결정 트리를 순차적으로 학습해 차종별 가격 수준, 감가, 주행거리의 비선형 관계와 상호작용을 표현한다.
4. 가격은 `log1p(price)`로 학습하고 예측 후 `expm1`로 원래 단위에 복원한다. 고가 차량의 영향력을 완화하려는 선택이며 원가격 MAE를 직접 최소화하는 학습은 아니다.

설정은 최대 250개 트리, 학습률 0.08, 트리당 최대 31개 말단 노드, 말단 노드 최소 40행, L2 규제 5다. 학습 구간 내부 10%를 조기 종료 판단에 사용했고 실제로는 250개 트리를 모두 사용했다. 난수 시드는 42다. 별도의 하이퍼파라미터 탐색은 하지 않았다.

## 검증 결과

등록일의 80% 분위수를 기준으로 나눴다. 같은 날짜의 행을 함께 배정하므로 정확히 80:20은 아니다.

- 학습: 2010-11-03~2020-08-31, **1,189,825행**
- 평가: 2020-09-01~2020-09-13, **312,292행**
- 학습·평가 VIN 중복: **0**
- 제조사+모델 조합: 학습 구간에서 **1,108종**
- 저장된 모델은 아래 성능을 평가한 모델과 동일하다. 평가 행을 합쳐 재학습하지 않았다.

| 모델 | MAE | RMSE | MAPE | R² |
|---|---:|---:|---:|---:|
| 전체 학습 가격 중앙값 | 9,673.52 | 14,019.10 | 54.99% | -0.0792 |
| 제조사+모델별 학습 가격 중앙값 | 6,242.74 | 9,191.35 | 41.53% | 0.5361 |
| 세 가지 입력의 트리 모델 | **3,395.90** | **5,771.75** | **14.59%** | **0.8171** |

제조사+모델별 중앙값 기준 대비 MAE를 약 **45.6%** 줄였다. MAE는 원본 가격 단위의 평균 절대 오차다. MAPE는 평균 절대 백분율 오차이며, 개별 예측이 ±14.59% 안에 들어온다는 뜻은 아니다. R²도 정확도 81.7%를 의미하지 않는다.

전체 평가 중 학습에 없던 차종은 9행이다. 위 전체 성능에서는 인코더의 학습 전체 평균으로 예측했다. 실제 예측 인터페이스는 미학습 차종을 거부한다. 실제 인터페이스가 지원하는 312,283행의 MAE는 3,395.49이며, 전체 성능과 유사하다.

### 해석 시 주의할 점

- 가격 관측일과 판매 완료일이 없어, 이번 날짜 분리는 **최근 등록 매물에 대한 평가**다. 미래 시점의 실제 시세 예측 성능을 증명하지 않는다.
- `listed_date`는 등록일이다. 가격이 나중에 갱신되었을 수 있어 등록일 기준 차령과 가격 관측 시점의 차령이 다를 수 있다.
- 같은 차종·차령·주행거리라도 트림, 사고 이력, 옵션, 상태에 따라 가격이 다르다. 요청한 세 가지 입력만으로는 이 차이를 구별할 수 없다.
- 원본의 필터 범위 밖 차량이나 2026년 현재 시세로 일반화할 근거는 없다. 최신 시세 예측에는 최신 매물 및 가격 관측일을 확보해 재학습해야 한다.

## 재현 및 파일

두 원본 CSV를 이 디렉터리에 둔 상태에서 실행한다. 전처리는 약 10GB의 원본 CSV를 순차적으로 읽으며, 충분한 메모리와 디스크 공간이 필요하다.

```bash
python3 prepare_data.py
OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4 python3 train_model.py
OMP_NUM_THREADS=4 python3 -m unittest -v test_price_model.py
```

| 파일 | 역할 |
|---|---|
| `prepare_data.py` | 원본 대조, 중고차 선별, 차령 생성 |
| `train_model.py` | 학습·평가, 모델 저장 |
| `price_model.py` | 입력 검증과 Python 예측 인터페이스 |
| `predict.py` | 명령행 예측 |
| `test_price_model.py` | 저장 모델 재현, 입력 검사, 3개 Feature 계약 검증 |
| `artifacts/price_model.joblib` | 학습된 인코더·트리·입력 지원 정보 |
| `artifacts/metrics.json` | 전체·지원 차종·차령 구간별 평가 수치 |
| `artifacts/data_audit.json` | 전처리 단계별 행 수 |
| `artifacts/prediction_examples.json` | 평가 행 10개의 실제값·예측값 |
| `artifacts/training_data.pkl` | 재학습용 전처리 데이터 |

`joblib`과 `pickle` 파일은 신뢰할 수 있는 파일만 불러온다. 검증한 환경은 Python 3.11.9, scikit-learn 1.8.0, pandas 3.0.3, NumPy 2.4.5, joblib 1.3.2다.
