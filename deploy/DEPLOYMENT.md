## 검증 결과

- FastAPI 테스트 **18개 통과**: 저장 모델 예측·경고 일치, 잘못된 입력 거절, 준비 상태, 누락 모델, 동시 요청 및 취소 처리.
- Next.js **16.3.5** 정적 빌드·TypeScript 검사 성공. npm audit 결과 취약점 **0개** (검사 시점).
- 공개 IP에서 HTML 및 정적 리소스 **7개** 정상 응답.
- 사고 이력 없음·있음·모름 **세 입력 모두** 로컬 모델과 배포 API의 가격·경고가 일치.
- 지원 범위 밖 입력 **422**, 큰 요청 **413**, 과도한 요청 **429** 확인. 동시 추론 포화 시 의도한 **503** 반환.
- 약 1req/s로 정상 요청 **30회**, 오류 **0건**, p50 **103.7ms**, p95 **138.3ms**. 외부 HTTP 왕복 포함의 짧은 표본이며 지속 처리량 보장은 아니다. 최초 설계의 5분 부하 시험은 수행하지 않았다.
- EC2 재부팅 시 일시 중단을 관측한 뒤 **31.9초**에 ready 및 실제 예측 복구. 고정 IP 유지.
- 재부팅 후 web/api 컨테이너 모두 **healthy**. 관측 메모리: web 약 **10MiB**, API 약 **211MiB**.
- 최초 배포이므로 이전 운영 릴리스로의 롤백 실험은 하지 않았다. 재배포 및 롤백 절차는 README에 있다.
- 브라우저 조작 기반 E2E/화면 검사는 수행하지 않았다. 폼의 로딩·오류·입력 변경 처리는 코드와 타입 검사로 확인했다.
